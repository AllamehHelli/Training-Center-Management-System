# راهنمای قرار دادن فونت‌های محلی در گیتهاب (Local Fonts)

برای استفاده از فونت محلی در کل سامانه:

1. فایل‌های فونت خود با پسوند `.ttf` (یا `.woff2` / `.woff`) را در همین پوشه (`public/fonts/`) قرار دهید.
2. نام‌گذاری پیشنهادی استاندارد:
   - `font-regular.ttf` (برای متن‌های عادی با وزن معمولی ۴۰۰)
   - `font-bold.ttf` (برای تیترها و دکمه‌ها با وزن پررنگ ۷۰۰)
   - `font-medium.ttf` (اختیاری برای وزن ۵۰۰)

به محض پوش کردن این فایل‌ها روی گیتهاب یا قرار دادن در هاست، سیستم به صورت کاملاً آفلاین و محلی از این فونت‌ها استفاده می‌کند و وابستگی به اینترنت خارجی یا Google Fonts قطع خواهد شد.
