# سامانه جامع مدیریت ثبت‌نام، مالی و آموزشی موسسه علامه حلی
> **Allameh Helli Registration, Finance & Academic Management System**

سامانه مدرن، یکپارچه و بهینه‌سازی‌شده برای مدیریت فرآیندهای ثبت‌نام، کلاس‌بندی، امور مالی، اقساط، سوابق تحصیلی دانش‌آموزان، اساتید، مشاوران و همگام‌سازی سفارشات فروشگاه ووکامرس.

این پروژه برای محیط‌های هاست اشتراکی و سرورهای اختصاصی طراحی شده و به‌طور کامل از معماری ترکیبی **فرانت‌اند مدرن React SPA + بک‌اند بومی PHP و دیتابیس MySQL** پشتیبانی می‌کند (بدون نیاز به نصب Node.js روی سرور cPanel).

---

## 🌟 قابلیت‌های کلیدی سامانه

1. **داشبورد مدیریتی و هوش آماری:**
   - نمودارهای مالی لحظه‌ای، تفکیک درآمدهای نقد و اقساط، نرخ رشد ثبت‌نام‌ها
   - فیلتر هوشمند بازه‌های زمانی تقویم جلالی (امروز، این هفته، این ماه، امسال و بازه سفارشی)
   - جستجوی سریع هوشمند (`Command Palette`) برای دسترسی به پرونده‌ها و دوره‌ها

2. **مدیریت پرونده و ثبت‌نام دانش‌آموزان:**
   - پرونده جامع دانش‌آموزی شامل کدملی، سوابق تحصیلی، اطلاعات اولیا، مشاور اختصاصی و معدل
   - اعتبارسنجی دقیق کد ملی، شماره موبایل و جلوگیری از ثبت اطلاعات تکراری
   - ورود دسته‌جمعی دانش‌آموزان از طریق فایل اکسل/CSV همراه با گزارش اعتبارسنجی
   - صدور گواهی و پرینت فرم‌های ثبت‌نام استاندارد

3. **مدیریت کلاس‌ها، زنگ‌ها و اساتید:**
   - تخصیص هوشمند زنگ‌های زوج، فرد یا سفارشی همراه با کنترل ظرفیت صندلی‌ها
   - بانک جامع اساتید و مشاوران با فیلتر پایه‌ها و رشته‌های تحصیلی
   - زمان‌بندی زنگ‌های درسی و پیشگیری از تداخل کلاسی

4. **سیستم مالی، حسابداری و دفترچه اقساط:**
   - محاسبه خودکار مبالغ کل، تخفیف‌ها، پیش‌پرداخت و جدول‌بندی اقساط ماهانه
   - ثبت وصولی‌ها، تسویه کامل، بازپرداخت (Refund) و تغییر وضعیت پرداخت اقساط
   - پیگیری هوشمند مطالبات معوق، سررسیدهای آتی و هشدارهای مالی

5. **آرشیو چندساله دوره‌های تحصیلی (Multi-Year):**
   - سوییچ سریع میان سال‌های تحصیلی مختلف (مانند ۱۴۰۳-۱۴۰۴ و ۱۴۰۴-۱۴۰۵)
   - حالت فقط‌خواندنی محافظت‌شده برای دوره‌های بایگانی‌شده با هشدار بصری

6. **یکپارچه‌سازی امن با ووکامرس (WooCommerce Sync):**
   - اتصال به فروشگاه آنلاین، دریافت و تطبیق سفارشات وب‌سایت با پرونده دانش‌آموزان
   - محافظت کامل از کلیدهای Consumer Key و Consumer Secret در لایه سرور

7. **سیستم ممیزی، خطایابی و گزارش‌گیری (`System Diagnostics & Logs`):**
   - ثبت لحظه‌ای کلیه رویدادهای سیستمی، خطاهای شبکه، همگام‌سازی و پایگاه داده
   - خروجی استاندارد JSON و CSV (سازگار با اکسل) با یک کلیک
   - کپی گزارش متنی تشخیصی برای پشتیبانی فنی سرور
   - بازیابی و بارگذاری ۵ داده نمونه استاندارد با یک کلیک

│   └── types.ts            # تعاریف تایپ‌های TypeScript
├── .env.example            # نمونه متغیرهای محیطی
├── .htaccess               # رول‌های آپاچی برای استقرار در ریشه وب‌سرور

├── tsconfig.json           # تنظیمات کامپایلر تایپ‌اسکریپت
└── vite.config.ts          # تنظیمات باندلر Vite

## 🚀 راه‌اندازی و اجرای محلی (Development)

برای اجرای فرانت‌اند در محیط لوکال:

```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. اجرای سرور توسعه فرانت‌اند
npm run dev
```

سامانه روی آدرس `http://localhost:3000` اجرا خواهد شد. در حالت محلی، سیستم به‌صورت خودکار در مود LocalStorage کار می‌کند و تمامی امکانات بدون نیاز به سرور در دسترس هستند.

## 📦 بیلد و استقرار در هاست cPanel

### روش ۱: استقرار خودکار با گیت‌هاب اکشن (توصیه‌شده)

کافی است این متغیرها را در بخش **Settings > Secrets and variables > Actions** مخزن گیت‌هاب خود تعریف کنید:
* `FTP_SERVER`: آدرس سرور FTP (یا IP هاست)
* `FTP_USERNAME`: نام کاربری FTP
* `FTP_PASSWORD`: رمز عبور اکانت FTP

با هر `git push` به شاخه `main`، فرانت‌اند به‌طور خودکار بیلد شده و فایل‌ها مستقیماً در هاست بارگذاری می‌شوند.

### روش ۲: استقرار دستی

```bash
# ایجاد خروجی بهینه‌سازی‌شده برای تولید
VITE_API_BASE=/api npm run build
```

محتویات داخل پوشه `dist/` (شامل فایل `index.html`، پوشه `assets`، پوشه `api` و فایل‌های `.htaccess`) را فشرده کرده و در مسیر ساب‌دامین در `public_html` یا ریشه هاست cPanel اکسترکت نمایید.

## 🗄️ تنظیم پایگاه داده MySQL در cPanel

1. در cPanel به بخش **MySQL Databases** رفته و دیتابیس و کاربر مربوطه را بسازید و دسترسی کامل (All Privileges) به آن بدهید.
2. فایل `.env` یا `api/config.php` را در ریشه هاست باز کرده و مشخصات دیتابیس را قرار دهید:
   ```php
   'db' => [
       'host' => 'localhost',
       'port' => '3306',
       'dbname' => 'your_cpanel_dbname',
       'user' => 'your_cpanel_dbuser',
       'pass' => 'your_strong_password',
       'charset' => 'utf8mb4'
   ],
   'jwt_secret' => 'کلید_امنیتی_تصادفی_و_طولانی_شما'
   ```
3. جداول پایگاه داده در اولین درخواست به‌صورت خودکار ساخته می‌شوند. همچنین می‌توانید فایل `api/schema.sql` را در phpMyAdmin ایمپورت کنید.
